# Core Game Mechanics

> Design document — not all features are implemented. Implementation status shown as [done/total] where known.

## 1. Turn-Based System [0/10]

- Each action (move, attack, ability) consumes **Action Points (AP)**
- Initiative roll determines turn order at encounter start
- Status effects can alter AP or block actions
- Environmental effects (weather, timed events) occur at fixed intervals
- Physics: fire spreads, liquids flow/mix/stain, acid corrodes
- Players can end turn early (strategic choice)

## 2. Player Movement & Interaction [0/6]

- 8-directional movement (including diagonal)
- **Inspection Mode**: ASCII art examination of significant entities/landmarks/writings
- **Inventory inspection**: ASCII art per item, changes with condition (pristine/worn/damaged)
- **Line of Sight**: bracket-lib shadowcasting; abilities/items can alter it
- **Cover System**: reduces hit chance, enables stealth
- **Stealth**: lighting + crouching + noise management

## 3. UI and HUD [0/4]

```
|---------------------------------------------------------------|

|                                          |  Target mob + gear |

| Active skill/gear hotkeys | Event log                        |

```

HUD stats: HP, AP, AR (armor), RE (reflex), MS (move speed), PSY (psychic energy), W (weight), currency, time, storm timer.

## 4. Map & Environment [0/5]

- **Tile-based grid** — each tile has terrain type, elevation, biome
- **World map layers**: biome → terrain → elevation → resources → POIs (noise + WFC for layers 1–3; procedural placement for 4–5)
- **Lazy tile generation** — tiles generated on first visit; seed = world seed + tile coords
- **Connectivity constraint** — generated tile must have one connected open area
- **Subterranean layers** — caves/dungeons accessible via surface entry points
- **Dynamic lighting** — light sources, time of day, weather affect visibility

## 5. Exploration

- **Auto-explore**: A* pathfinding to nearest unexplored tile; stops on danger/items
- **Explored areas**: static terrain stays visible (desaturated); dynamic entities only visible in LoS

## 6. Combat System [0/10]

**Tracked stats** (shown on HUD): HP, AP, AR, RE, MS, PSY

**Non-tracked stats** (influence gameplay): Strength (melee dmg, carry), Intelligence (skill effectiveness), Endurance (HP, resistance), Agility (speed, dodge), Charisma (NPC, barter)

- **Melee**: weapon or unarmed (kick, headbutt, bite, grapple, spit)
- **Ranged**: weapons, thrown, explosives; affected by accuracy/range/LoS
- **Psychic**: PSY-powered abilities (mind control, telekinesis, solar ray, psychic blast)
- **Body targeting**: aim at head/torso/limbs for different hit chances and damage multipliers
- **Cover**: reduces hit chance
- **Status effects**: stunned, poisoned, burning, etc.

## 7. Enemy AI & NPCs [0/8]

Demeanors: Aggressive (attack on sight) | Defensive (cover-seeking) | Neutral | Friendly | Pacifist

**Aggro system**: enemy focuses on highest-aggro target; aggro generated by damage, healing, threatening abilities.

Enemies can use items (health packs, grenades, buffs) — depends on type/intelligence.

## 8. Character Progression [0/7]

- **XP** from combat, exploration, quests → level up
- **Level up** grants: Skill Points (unlock/upgrade abilities) + Stat Points (core stats)
- Skill trees, perks/traits, specializations — under consideration
- **Respec** available at specific game points
- **Companion progression** — companions have own skill systems
- **Unique backgrounds** — starting bonuses, skills, storylines
- Supports unconventional builds with significant pros/cons

## 9. Inventory & Equipment [5/5] ✅

- Weight-limited inventory; exceeding capacity reduces MS
- Equipment slots: weapon, armor, accessory
- Item inspection with ASCII art (condition affects visual)
- Equipment durability — degrades with use, affects stats, can break

## 10. Crafting System [4/6]

- Data-driven recipes in `data/recipes.json`
- Material gathering from environment
- Crafting stations required for advanced recipes (forge, alchemy table, mirror shrine)
- Item modification: enchantments, refinement, combining
- Recipe discovery: schematics, NPC interactions, experimentation
- Adaptive crafting: some recipes require specific adaptations or environmental conditions

## 11. Quests & Storytelling [5/6]

- Data-driven quests with objective types: kill, collect, reach, talk, interface
- Quest discovery: NPCs, environment (journals, terminals), location triggers
- Branching narratives based on choices, adaptations, faction allegiances
- **Faction reputation** affects quest availability, dialogue, NPC behavior
- Story flags track decisions persistently
- Environmental storytelling via lore items and world state

## 12. Audio [0/4]

- Ambient soundscapes (wind, glass chimes, storm rumbles)
- UI feedback cues
- Combat audio (attack types, status effects)
- Adaptive music (exploration, combat, faction areas)

## 13. Modularity / Modding [2/5]

- Data-driven content (JSON) — core mod surface
- Mod loading with load order and conflict resolution
- Script hooks (potentially Lua) for custom behaviors
- Mod documentation and JSON schema
- Validation and error handling for mod data
